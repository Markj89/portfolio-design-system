# Getting Started
Storybook is a design system for reusable componenets that helps developeers and other contributors build UI faster.


## Install 
All components are built in React.

Add Storybook to your project
`npm install --save @storybook/design-system`

### **Use**
Import components you want into your UI
`import { Button } from '@storybook/design-system';`

and use them like so

```
    const example = () => (
        <div>
            <Button classes="primary" onMouseDown={() => 0}>Do something</Button>
        </div>
    );
```

### **Run and develop SDS locally**

Clone the [SDS GitHub project](https://github.com/storybookjs/design-system) then start Storybook.

`yarn && yarn run storybook`
