# Portfolio Design System

This design system provides a collection of reusable and adaptable components, assets and logic that can be used and compiled to build different products.

## Installation

All components are built with:
- React
- Vite
- NextJS

Add Storybook to your project with `npm`

```
npm install --save @storybook/portfolio-design-system
```

### **Use**

Import components you want into your UI
`import { Button } from '@storybook/portfolio-design-system';`

and use them like so

```
    const example = () => (
        <div>
            <MJButton classes="primary" onMouseDown={() => 0}>Do something</MJButton>
        </div>
    );
```

### **Run and develop locally**

Clone the [Markj89 GitHub project](https://github.com/Markj89/portfolio-design-system) then start Storybook.

`npm && npm run storybook`
