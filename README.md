# Portfolio Design System

Design System for my WordPress Portfolio built in React

## Prerequisites


### Project setup
```
npm install
```


### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Run Tests
```
npm run test
```
